오픈클로로 쓰는 순서

  1. 장면을 말한다“태블릿 보는 어머니 컷 H3로 만들어 줘”
  2. 프롬프트 작성h3-prompt-writing 스킬이 화면·카메라·소리를 정리
  3. 무료 미리보기보낼 내용과 설정을 확인
  4. 승인“응, 만들어” 해야 요금이 나가는 생성 시작
  5. 저장·보고output 폴더에 mp4 저장, 경로 알림

터미널 명령

# 한 편 만들기 (요금 발생)
cd ~/h3-video && python3 h3_video.py prompts/coffee.txt

# 보낼 내용만 확인 (무료)
python3 h3_video.py prompts/coffee.txt --dry-run

# 대기열에서 최대 3편 생성
python3 h3_video.py --queue --max-jobs 3

# 오픈클로 상태 확인 · 대시보드 열기
